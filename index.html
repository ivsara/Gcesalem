System Architecture & Viva Reference

1. Role-Based Access Control (RBAC) • Administrator (admin / admin123): Full control over users, departments, all notices, pins, and portal defaults.
• Faculty (faculty_cse / faculty123): Publish/edit/delete notices and attachments for assigned department.
• Student (student_cse / student123): View public + department notices, preview/download attachments, customize theme.
2. Full-Stack & Hybrid Deployment • GitHub Pages Live Mode: Runs directly in the browser on GitHub Pages with persistent local storage, real file attachment previews, and instant role switching.
• FastAPI + SQLite Server Mode: Run cd webapp && uvicorn main:app --reload for Python REST API + SQLAlchemy ORM.
• Android App: Native Kotlin + Jetpack Compose + Room SQLite in app/.
